# Reinforcement Drills

Short, focused exercises for a single concept. Do one when the checker
recommends it, or whenever a concept feels shaky. Each takes a few minutes
and leaves your repository as it found it (or adds a tiny commit).

| Drill | For when |
|-------|----------|
| [reading-git-status.md](reading-git-status.md) | you are not sure which section of `git status` means what |
| [staging.md](staging.md) | files end up in the wrong commit, or you are unsure what `add` did |
| [markdown-links.md](markdown-links.md) | links do not resolve |
| [branch-switching.md](branch-switching.md) | you keep committing on the wrong branch |
| [reading-diffs.md](reading-diffs.md) | `git diff` output looks like noise |

None of these are required. The checker does not track them.
